# Pleos Pit Wall 4.2.0

최신 Pleos UI와 Gleo action 응답을 구현한 모듈입니다. 연결 코드가 같은 웹의 최신 분석 결과를 정차 상태에서 자동으로 조회합니다. 분석 대상은 주행 시작부터 분석 버튼까지이며 랩 완주 조건은 없습니다.

`SHOW_LATEST_RECOMMENDATION`, `EXPLAIN_RECOMMENDATION`, `SHOW_SESSION_METRICS` action을 처리합니다. 실제 Gleo 음성 호출과 App Market 심사는 별도입니다.

빌드 방법과 전체 검증 범위는 [상위 개발 안내](../../docs/BUILD.md)를 참고하세요.
